# 钣金站 jlc-bj.com

嘉立创钣金是独立站，同一个账号直接登录。入口：`www.jlc-bj.com` →「在线报价/下单」→ 钣金加工，或直接 `www.jlc-bj.com/order/#/placeOrder`。一件起做，最快 24h 发货。

## 走 STEP，不走 DXF

2D 图纸（DXF）传上去之后要**在网页画布上手动框选轮廓**才会自动报价，那个画布是跨域 iframe，脚本进不去。而且 2D 通道明确不支持折弯和焊接。

3D STEP 传上去自动解析：轮廓、板厚、折弯全部从模型读，直接出价。**所有件都建成 STEP 传**，包括纯平板件。

手写的 DXF 常常解析出「轮廓数量 0」，要用 `ezdxf` 之类的标准库生成 —— 不过既然走 STEP，DXF 这条路只在对方明确要 2D 图纸时才用。

## 报价里件数比面积值钱

开机、装夹、氧化挂架这些固定成本按**件**摊，不按面积。所以：

- 把一块大板拆成两块小板，料省了，价常常不降反升。
- 折边 + 打孔比同尺寸纯平板只贵一点点（一对侧板约 ¥52），刚性提升非常划算。
- 估算别按 m² 线性外推，小件的每平米单价明显高。

## 页面自动化要点

用 chrome-devtools 操作这个站时：

- **点击要派发完整事件序列**，React 合成事件不认单个 `click()`：
  ```js
  const fire = el => ['pointerdown','mousedown','pointerup','mouseup','click']
    .forEach(t => el.dispatchEvent(new MouseEvent(t, {bubbles:true, cancelable:true, view:window})));
  ```
- **「复用到全部」按钮对合成事件不响应**，逐个文件设材料和工艺。
- 选项是卡片不是 select：找文本完全匹配的叶子节点，再往上找到第一个尺寸够大的祖先当点击目标。
- 价格从 `document.body.innerText` 里正则取：`/单价：\s*¥([\d.]+)\/件[\s\S]{0,60}?税费：\s*¥([\d.]+)[\s\S]{0,90}?¥([\d.]+)/`。
- 每次改材料/工艺后等 2s 以上再读价，它是异步重算的。

## 结构常识

2mm 铝平板在家具尺度上不能当平板用：

- 1133×710 的背板、1133×310 的侧板，2mm 平铝中间会明显起伏（oil-canning）。
- 2mm 平铝层板跨 710mm 承 6kg，挠度约 **18.8mm** —— 直接塌了。18mm 多层板同跨同载只塌 0.26mm。
- 结论：铝板件基本都要折边。**2mm 料、折边 15mm、内 R2 外 R4** 是跑通过的一组参数，折边上打 Φ5.5 过孔（配 M5）拧在型材立柱内侧面。

折弯圆角的通行规则是内 R = 料厚、外 R = 2×料厚，`bend-part.py` 就是这么算的 —— 上面那组值是它在 T=2 时的结果。换料厚时圆角跟着变，别把 R2/R4 当成固定值抄。

**还没问到的**：最小折边高、最小孔边距、折弯机单次能折的最大长度。件长超过 1m 的折边件建模前先确认，不然可能要分段。

建模模板见 [../scripts/bend-part.py](../scripts/bend-part.py)。
